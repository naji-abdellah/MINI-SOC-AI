# Machine Learning Detection Module

## Purpose
Feature engineering, training, and comparative evaluation of:
1. **Unsupervised Anomaly Detection:** Isolation Forest.
2. **Supervised Classification:** XGBoost.

## Roadmap (Milestone 3)
- [ ] Feature extraction pipeline (sliding windows, request frequency, entropy, error ratios).
- [ ] Isolation Forest baseline model.
- [ ] XGBoost classification model on labeled dataset.
- [ ] Metric evaluation script (Precision, Recall, F1, PR curves, Confusion Matrices).
- [ ] Concept drift and train/test leakage break-it experiments.
